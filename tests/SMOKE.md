# Smoke checklist

Run `python main.py` and walk this list once before a build.

- Boot: the splash can be skipped and the main menu shows Start, Continue, Settings, Credits, and Quit.
- Move: A and D walk the player along the Whispering Path.
- Jump: Space leaves the ground and lands again.
- Hit: J swings the sword and an enemy loses health.
- Block: K raises the shield and a matching-height shot does not hurt.
- Inventory: I opens the bag. A potion heals. A weapon can be equipped.
- Talk: E beside the Owl Keeper types a line, a choice can be picked, and the box closes.
- Save: Esc, then Save, writes the slot.
- Quit: Quit from the pause menu or the main menu closes the window.
- Continue: Continue from the main menu, or from game over, returns to Whispering Path with quests and items intact.
